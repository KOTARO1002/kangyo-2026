# 管業ドリル 2026｜単元別 網羅問題集

2026年12月6日（日）実施の管理業務主任者試験に向けた、**単元別の網羅型問題集**です。
姉妹サイト「[22週間 合格プログラム](../)」でインプットした内容を、論点ごとに大量の問題で固めるために作りました。

**公開URL**：https://kotaro1002.github.io/kangyo-2026/drill/

サーバー側の処理はなく、ブラウザだけで動作します。

---

## 収録内容

- 全31単元（8分野）
- 一問一答（○×）と四肢択一（本試験形式）、全問に解説・根拠条文つき
- 単元ごとに論点を立て、論点ごとに複数問を割り当てて網羅性を確保
- 難易度（基本・標準・難）表示

| 分野 | 単元 |
|---|---|
| 区分所有法 | 総則・専有/共用部分・敷地利用権／共用部分の管理・変更／管理者・規約／集会・決議／管理組合法人／義務違反者・復旧・管理命令／建替え・再生・団地 |
| 標準管理規約 | 専有・共用の範囲・用法／管理・費用負担／総会／理事会・役員／会計・雑則・団地型・複合用途型 |
| 委託契約書 | 本文／別表・コメント |
| 民法 | 総則／物権・共有・担保物権／債権総論／契約各論／賃貸借・借地借家法／不法行為・相続 |
| その他法令 | 宅建業法／品確法・瑕疵担保履行法・消費者契約法・個人情報・登記ほか |
| 適正化法 | 定義・登録・管理業務主任者／業務規制・分別管理・監督・管理計画認定 |
| 会計・税務 | 管理組合会計・仕訳／財務諸表・滞納対応・税務 |
| 建築・設備 | 建築基準法／構造・材料・劣化診断／給排水・ガス／電気・消防・昇降機ほか／大規模修繕・長期修繕計画・修繕積立金 |

2026年4月1日施行の改正区分所有法（令和7年法律第47号）、令和7年10月改正の標準管理規約に対応しています。

## 機能

| 機能 | 内容 |
|---|---|
| 単元演習 | 形式（一問一答／四肢択一）・対象（全問／未解答／前回×／未習得）・問題数・論点を選んで出題 |
| 復習 | 前回間違えた問題を、新しく間違えた順に最大30問 |
| 未解答から20問 | 全単元から、まだ解いていない問題をランダム出題 |
| 分野から20問 | 未習得を優先して分野単位で出題 |
| 本番形式 模試 | 四肢択一50問・2時間。本試験の分野配分で出題し、最後にまとめて採点 |
| ブックマーク | ★を付けた問題だけを出題 |
| 習得管理 | 2回連続正解で「習得」。単元・論点ごとに習得率を表示 |
| 進捗の移行 | 設定画面で記録を文字列化し、別端末に貼り付けて引き継ぎ |

PCではキーボード操作に対応しています（○×は O/X、四肢択一は 1〜4、次へは Enter）。

### 問題の追加・修正

`data/uNN.js` の `ox`（一問一答）または `mc`（四肢択一）の配列に追記します。
進捗は「単元ID＋配列の位置」で記録しているため、**既存の問題を削除・並べ替えすると記録がずれます**。修正は書き換え、追加は末尾に足してください。

---

## 使い方

- ホーム画面に追加するとアプリのように起動できます（iPhone：Safariの共有ボタン → ホーム画面に追加）
- 進捗はブラウザごとに保存されます。PCとスマホで使う場合は、設定画面の「別の端末へ移す」で記録をコピーしてください
