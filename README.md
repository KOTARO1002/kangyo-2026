## 公開手順（GitHub Pages）

1. GitHubで新しいリポジトリを作成する（名前の例：`kangyo-2026`、**Public**を選択）
2. 「uploading an existing file」から上記ファイルをすべてドラッグ＆ドロップし、Commit
3. リポジトリの **Settings → Pages** を開く
4. Source を「Deploy from a branch」、Branch を `main`、フォルダを `/ (root)` にして Save
5. 1〜2分待ってページを再読み込みすると、上部に公開URLが表示される

### 更新方法

内容を差し替えるときは、リポジトリ画面の **Add file → Upload files** から
同じ名前のファイルを再アップロードして Commit するだけです。1〜2分で反映されます。

## 使い方

- ホーム画面に追加すると、アプリのように起動できます
  - iPhone（Safari）：共有ボタン → ホーム画面に追加
  - Android（Chrome）：メニュー → ホーム画面に追加
- 解答するとその場で正誤判定と解説が表示され、進捗が自動保存されます
- 週ごとに解答をリセットできます
- **進捗は端末ごとに保存されます。** PCとスマホでは別々の記録になるため、
  使う端末を1つに決めておくと混乱しません
